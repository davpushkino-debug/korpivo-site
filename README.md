# Сайт Королевского пивоваренного завода

Обычный статический сайт. Нет баз данных, CMS, форм и сборки. Подойдёт любой хостинг:
Beget, Timeweb, REG.RU, а для просмотра — даже бесплатный GitHub Pages.

## Как выложить на хостинг

1. Откройте файловый менеджер хостинга или подключитесь по FTP, например через FileZilla.
2. Зайдите в папку сайта. Обычно это `public_html` или `www`.
3. Загрузите туда **всё содержимое** папки `korolevsky-site`. Не саму папку, а то, что внутри:
   `index.html`, `privacy.html`, `css`, `js`, `img`, `fonts`, `files`,
   `.htaccess`, `robots.txt`, `sitemap.xml`.
4. В панели хостинга подключите бесплатный SSL-сертификат (Let's Encrypt).

Чтобы обновить сайт, загрузите заново только изменённые файлы.

Домен прописан как **korpivo.ru**. Если домен другой, замените его в `index.html`
(первые строки), в `robots.txt` и в `sitemap.xml`.

## Структура

```
index.html          — вся страница (тексты разделов, телефон, реквизиты)
privacy.html        — страница про cookie и Метрику (нужна, только если Метрика включена)
js/data.js          — СОРТА, МАГАЗИНЫ, НАСТРОЙКИ (меняется чаще всего)
js/main.js          — логика: фильтр, карточка сорта, карта, Метрика
css/style.css       — оформление (цвета — в самом начале файла)
img/labels/         — этикетки сортов
img/tags/           — ценники сортов
img/production/     — фото производства
files/price-list.pdf — прайс-лист для скачивания
```

Папка `tools/` (рядом с `korolevsky-site`) нужна для сборки прайса. На хостинг её **не загружайте**.

## Частые правки

### Добавить или изменить сорт
Откройте `js/data.js`, скопируйте блок любого сорта `{ id: ... },` и поменяйте поля.
Описание всех полей есть в начале файла. Порядок на сайте такой же, как в файле.
- Временно скрыть сорт: допишите `hidden: true`.
- Плашка «Новинка» или «Сезонное»: `badge: 'Новинка'`. Сорта с «Новинкой» попадают в фильтр «Новинки».
- Сорт снимается с производства: `ending: true`. Плитка станет серой с пометкой «Последняя партия»,
  карточка не откроется, сорт не войдёт в число сортов. Когда остатки закончатся, поставьте `hidden: true`.

Крепость, плотность и фильтрацию берите только из гугл-таблицы «Декларируемые сорта».
Срок годности официальный: фильтрованное — 60 суток, нефильтрованное — 30.

Число сортов на сайте («27 сортов») пересчитывается само.
Сразу видно 3 ряда плиток (на телефоне — 5 штук), остальные открываются кнопкой «Показать ещё».
Число рядов меняется в `js/data.js` → `settings.beerRows`.
Вручную его нужно поправить только в описании для поисковиков: `index.html`, строки `description`.

### Этикетка (лэйбл) в карточке сорта
Картинки лежат в `img/labels/` (квадратные лэйблы) и `img/tags/` (ценники).
В `js/data.js` у сорта поле `label`:
- `label: 'img/labels/temnoe-u.webp'` — одна картинка;
- `label: { f: 'img/labels/pilsner-f.webp', u: 'img/labels/pilsner-u.webp' }` — две,
  в карточке появится переключатель «Фильтрованное / Нефильтрованное»;
- `label: ''` — пустая рамка «Этикетка скоро появится».

Лэйблы получены из PDF в `Desktop\Layouts\Label (LB)`. Их обрезали по линии реза, чтобы убрать метки и цветовые шкалы.
Скрипт для этого лежит в `tools/labels/labels.mjs`. Проще всего попросить Claude перевести новые PDF.

Перед публикацией сверяйте крепость и плотность на лэйбле с декларацией.
Лэйблы с расхождениями лежат в `tools/labels/на проверку/` и на сайт не выставлены.

### Ссылка «Ценники для печати»
В `js/data.js` → `settings.tagsUrl` вставьте ссылку на папку Google Диска с PDF ценников.
У папки должен быть доступ «Все, у кого есть ссылка». Пока поле пустое, ссылки на сайте нет.

### Магазины на карте
Раздел `shops` в `js/data.js`. Координаты берите в Яндекс Картах:
правый клик по точке → «Что здесь?» → скопируйте цифры вида `55.9162, 37.8263`.
Карта — виджет Яндекс Карт, ключ API не нужен.

### Прайс-лист (PDF)
1. Цены, группы и даты лежат в `tools/price/prices.js`. Названия и описания берутся из `js/data.js`.
2. Дважды щёлкните `tools/price/build-price.cmd`: он соберёт новый `files/price-list.pdf`.
   Нужен установленный Google Chrome.
3. Загрузите `files/price-list.pdf` на хостинг. Ссылка на сайте останется прежней.

### Яндекс.Метрика
1. Создайте счётчик на metrika.yandex.ru.
2. Впишите его номер в `js/data.js` → `settings.metrika: '12345678'`.

После этого внизу появится плашка про cookie. Метрика включается только после согласия посетителя (152-ФЗ).
Цели уже настроены: `phone_click` (нажали на телефон), `sort_open` (открыли карточку сорта),
`tags_open` (открыли ценники для печати). Их нужно один раз добавить в настройках счётчика как
«JavaScript-событие» с этими же названиями.

### Телефон
Встречается в `index.html` в двух видах: `+79855486346` (в ссылках) и `985 548-63-46` (в тексте).
Ещё он есть в `privacy.html` и `tools/price/price.html`.

### Telegram и почта для кнопок «Написать»
В `js/data.js` → `settings.telegram` (без @) и `settings.email`.
Кнопка открывает окно «Где вам удобнее написать?» с готовым текстом. Если в карточке выбран сорт, его название тоже подставляется в текст.
В блоке «Контакты» Telegram и почта прописаны отдельно, в `index.html`.

### Реквизиты
Внизу `index.html` (строка `ООО «Королёвская пивоваренная компания» …`) и в начале `privacy.html`.

## Ссылка на конкретный сорт

(после `#sort-` идёт `id` сорта). Удобно отправлять магазинам.

## Проверка на своём компьютере
Достаточно открыть `index.html` двойным щелчком. Для карты нужен интернет.
